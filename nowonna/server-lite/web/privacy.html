개인정보 처리방침

시행일 2026년 11월 7일

나온나는 픽업하는 동안에만 필요한 정보를 쓰고, 픽업이 끝나면 지웁니다. 회원가입이 없고, 받는 사람은 앱을 설치하지 않습니다.

1. 처리하는 정보

누구의어떤 정보왜
운전자차 위치·진행 방향, 도착까지 남은 시간·거리, 도착·탑승 상태, 비상등 켜짐 여부받는 사람에게 차가 오는 모습과 도착 시간을 보여 주기 위해
운전자표시 이름(별칭), 차종·색상·번호판받는 사람이 차를 알아보기 위해 (등록한 경우만)
받는 사람이름, 전화번호 (운전자가 차량에 연결된 휴대폰 연락처에서 고름)픽업 링크를 보내기 위해. 전화번호는 웹 화면에 보여 주지 않습니다
받는 사람고른 만날 장소·한마디, 탑승 후 목적지, 장소 검색어, 링크를 연 시각장소 변경 요청과 운전자 내비 안내, '링크 확인' 표시를 위해
받는 사람 (선택)내 위치 ([내 위치] 버튼을 누른 경우만)만날 곳까지 걸어서 걸리는 시간을 계산하기 위해. 운전자에게 보내지 않습니다

2. 보관 기간과 삭제

  • 정보는 픽업이 진행되는 동안에만 서버 메모리에 있고, 별도 데이터베이스에 쌓지 않습니다.
  • 탑승이 감지되거나 운전자가 공유를 끝내면, 또는 시작 후 2시간이 지나면 링크가 만료되고 차 위치·비상등·받는 사람 전화번호·내 위치 계산 값을 즉시 지웁니다.
  • "공유가 끝났어요" 화면에 필요한 나머지 값(장소 이름, 상태, 시각)은 종료 후 24시간이 지나면 모두 지웁니다.
  • 서버 운영 기록에는 픽업 번호와 장소 이름만 남고, 이름·전화번호·한마디는 남기지 않습니다.

3. 외부에 전달하는 정보

나온나는 정보를 팔거나 광고에 쓰지 않습니다. 기능을 위해 아래 서비스에 필요한 값만 보냅니다.

  • SK open API (TMAP): 지도 표시, 경로·도보 시간 계산, 주소 찾기, 장소 검색을 위해 좌표와 검색어를 보냅니다.
  • 문자 발송 서비스: 실서비스에서 픽업 링크를 문자로 보낼 때 받는 사람 전화번호를 보냅니다. (현재 시연 버전은 문자를 보내지 않습니다)
  • 지도와 글꼴 파일은 브라우저가 TMAP·jsDelivr·unpkg 서버에서 직접 불러옵니다.

4. 이용자가 할 수 있는 것

  • 운전자는 차량 화면에서 언제든 공유를 끝낼 수 있고, 끝나는 즉시 위 정보가 지워집니다.
  • 받는 사람은 위치 권한을 허용하지 않아도 모든 기능을 쓸 수 있습니다 (걸어서 걸리는 시간만 빠집니다).
  • 차량 앱은 차량 상태를 읽기만 하고, 차를 제어하지 않습니다.

나온나는 현대자동차그룹 차량용 앱 개발 공모전 출품작이며, 이 방침은 시연 버전 기준입니다. 정식 서비스 전에는 개인정보 보호책임자와 문의처를 정해 이 페이지에 알립니다.
